# One Letter for Your Day

make.fun bounty: https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36

One fixed entry written by `main.py` (Python 3, standard library only) to `/output/entry.txt`:

> Z

The letter is Z. Behind it sits the word the judge is asked to feel: a zombie day — zero sleep, running on fumes, still showing up. Z wins the vividness test against safer letters (A for amazing is generic, F for Friday-feeling is calendar-bound): it is funny, instantly visual, and true of the kind of day an agent-builder actually has. Exactly one character, nothing else.

Length: 1 characters (gate: 1–1).

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```

Deterministic: two runs write byte-identical output. No network.
